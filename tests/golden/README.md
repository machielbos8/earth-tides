## Golden values (frozen 2026-10-08 from tag `round-1`)

The code is about to be restructured into the `earthtides` package (docs/package_plan.md). These
files make sure that nothing changes the numbers on the way. Both were generated by running the
code of tag `round-1` (commit 6afb638) in a temporary git worktree, not the working tree.

**Package level** (also in the release; part of the normal test suite and the CI gate):

* `cases.py`: the cases, each a function returning named numbers: spherical PREM (body tide,
  load Love numbers n = 2, 10, 100), hydrostatic PREM with fluid core and Coriolis (M2, O1, Mf:
  IERS parameters, k, the surface field at five colatitudes; elastic and anelastic), the
  flattened-Earth load Love numbers, and etide time series (iers, mhb, ddw).
* `round1.json`: their values (complex as [re, im]); written by `tools/make_golden.py`.
* `tests/test_golden.py`: compares, relative tolerance 1e-9 per quantity. Runtime 22 s.

**Paper level** (dev repo only; run by hand before a release or after a restructure):

* `paper_round1/`: outputs of the 15 paper-1 scripts and the examples ex1-ex5, written by
  `tools/paper_baseline.py baseline` (13 min, plus the two IERS comparisons with --workdir).
* `python tools/paper_baseline.py check [--workdir DIR --py-ext PY]` reruns them on the current
  code and compares number by number (one unit in the last printed digit; round-off zeros below
  1e-9 ignored); `stale` compares the committed results/ files with the baseline.

On 2026-10-08 seven committed results files and examples/ex5/hough1895.out were older than the
round-1 code; they were refreshed from the baseline. None of the paper's numbers changed: the
differences were round-off, a stale weak-solid-core DDW file that the paper does not use
(ddw1999_PREMs.txt), and the spurious "numerical mode" rows of the Hough example (the FCN rows,
219.41 days, are unchanged).

Regenerate only on purpose (a deliberate change of results, explained in the commit message):
`python tools/make_golden.py --tag <new tag>`.

**2026-10-09: re-frozen at tag `round-2`** (`round2.json`, used by `tests/test_golden.py`). The
inner-core Vp of PREM.dat/PREMs.dat was corrected (the row held the Vs gradient); all values change
by <= 5e-8 relative (the static zonal U0 by 3.6e-4 relative, 3e-8 absolute). `round1.json` and
`paper_round1/` are kept as the record of the round-1 code.
`tools/paper_baseline.py check` against `paper_round1/` now reports two expected differences from
the Vp correction: degree2_PREMs.txt and zonal_PREMs.txt (static weak-core runs; 8th digit, and the
degree-0 U0 in its 4th digit). Neither value is quoted in the paper.

**2026-10-09: re-frozen at tag `round-3`** (`round3.json`). The power-law part of the anelasticity
now uses the exact dispersion cot(alpha pi/2) instead of astyanax's 2/(pi alpha): the anelastic
values change by 1e-4 to 8e-4 (h0). The paper check reports the expected differences in
anelastic_PREMs, compare_models, coriolis_PREMs and depth_sensitivity (results/ refreshed).
